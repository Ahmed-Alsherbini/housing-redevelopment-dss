# أولويات تطوير الإسكان — بورسعيد

لوحة Streamlit عربية من صفحة واحدة: قائمة الأولويات، تفاصيل المشروع والمؤشرات، مقارنة مشروعين، وتصدير CSV.

## البيانات المعتمدة

الملف المصدر الحالي هو `data/sample/PortSaid_30_Projects_Updated_2026-11-01.csv`، وهو تحويل جدولي للملف المحدّث المرفق بتاريخ 1 نوفمبر 2026. يحتوي على 30 مشروعًا و41 عمودًا. يُحتفظ بالبيانات الأصلية لكل صف داخل سجل المشروع لأغراض التتبع، وتُستخدم الحقول القياسية للحسابات.

توزيع الحالة العامة في الملف: 25 متوسط، و1 رديء، و1 متهالك، و3 رديء ومتهالك. مجموع الوحدات المسجلة 22,160 ومجموع العمارات المسجلة 1,289؛ سجل واحد يفتقد العددين، ولذلك لا تُخترع له كثافة.

عند تشغيل التطبيق، تتم مزامنة الدراسة المعتمدة مع نسخة البيانات المحدّثة مرة واحدة لكل إصدار مصدر. يُسجل الاستيراد في سجل الإصدارات، وتُحفظ الدراسات الأخرى مستقلة. عند اختلاف عدد الصفوف أو تكرار المعرّفات، يتوقف الاستيراد بدل تحميل نطاق غير مطابق.

## الواجهة

- بحث بالاسم أو المعرّف وفلتر الحي.
- جدول أولوية واحد يضم الدرجة والحالة والقرار المسجل واكتمال البيانات.
- اختيار المشروع يعرض المؤشرات وقيم المصدر وأوزان الدراسة والأوزان المستخدمة فعليًا ومساهمتها بالنقاط.
- مقارنة مشروعين مع إظهار المعرّف في اسم كل مشروع، حتى عند تكرار الاسم.
- تصدير القائمة المصفّاة وتفاصيل المشروع المختار إلى CSV بترميز يدعم العربية.
- إعدادات الإدارة موجودة داخل القسم الجانبي القابل للفتح. لا يوجد تنقل بين لوحتي معلومات، ولا خرائط أو رسوم تكرر الجدول أو نموذج توصية إلزامي.

## المؤشرات والحسابات

تعتمد الدراسة ستة مؤشرات، بأوزان ثابتة مجموعها 100%:

| المؤشر | الوزن |
| --- | ---: |
| الحالة الإنشائية والعامة | 35% |
| الأهمية الاستراتيجية | 20% |
| العمر | 15% |
| كثافة الوحدات السكنية | 10% |
| الامتدادات | 10% |
| المرافق والبنية الأساسية | 10% |

تُحسب النقاط الموزونة لكل مؤشر = الدرجة من 100 × الوزن ÷ 100. الكثافة = عدد الوحدات السكنية ÷ المساحة بالفدان، ثم تُطبّق Min-Max على المشاريع النشطة الثلاثين. لا يُستبدل عدد العمارات بعدد الوحدات.

الامتدادات: يوجد = 100، لا يوجد = 0، والمفقود/غير الواضح لا يُحتسب. هذا المؤشر لا يثبت عدم قانونية الامتداد. المرافق: عدد المرافق المتصلة من أصل أربعة؛ وإذا كانت حالة أي مرفق مفقودة فلا يُفترض أنه غير متصل. الاتصال لا يقيس جودة الخدمة.

لا تُعاد قسمة الأوزان لتعويض البيانات المفقودة. تبقى مساهمات المؤشرات المتاحة ظاهرة، لكن الدرجة النهائية من 100 لا تُعرض إلا عند اكتمال حساب المؤشرات الستة. الدرجة أداة لدعم المراجعة والمعاينة وليست قرار إزالة أو ترميم.

## التشغيل والاختبارات

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
python -m pytest tests/ -q
```

تم التحقق من 30 اختبارًا بنجاح، بما فيها تشغيل الصفحة عبر Streamlit AppTest، البحث والتصفية والحالة الفارغة، مقارنة مشروعين لهما الاسم نفسه، استيراد 30 سجلًا، استبعاد المؤشر السابع، الحفاظ على الدراسات القديمة، وتطابق مجموع المساهمات مع الدرجة عند نقص البيانات.

قاعدة SQLite المحلية تُنشأ في `data/housing_dss.sqlite3`. هذا لا يضمن دوام البيانات عبر إعادة بناء حاوية Streamlit Community Cloud؛ لا تُعامل ملفات تشغيل الحاوية كأرشيف دائم.


## Updated scorecard (30-project scope)

The active six-indicator scorecard uses weights of 35% structural condition, 20% strategic importance, 15% building age, 10% housing units per feddan (Min-Max normalized within the 30-project scope), 10% extensions presence, and 10% utility connections. The weights total 100%. Missing or unclear values are not converted to zero; a final priority score is shown only when all six indicators are scorable. Utility connection measures connection only, not service quality, and extension presence does not independently establish legal status.
